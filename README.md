## Learning Path

A practical progression through this collection is:

1. Start with **OpenEMR Recon Rush** to practice application-focused reconnaissance.
2. Continue with **Scanline Services** to build service-discovery skills.
3. Explore **Files in the Fog** for file discovery and investigation.
4. Move to **FTP Cache Leak** and **Anonymous FTP to Root Shell** for FTP security concepts.
5. Practice **BuffemR Lab Launchpad** and **BuffemR Breakout** for application-focused CTF challenges.
6. Study **Keyring Break-In** and **Keyring Flag Trail** for keyring and flag-discovery exercises.
7. Continue with **Wildcard Grip** to understand wildcard-related security concepts.
8. Finish with **Cracking the Compress SUID** and **SUID Wildcard Keyring** for SUID and Linux privilege-escalation practice.

## How to Use the Labs

- Read the instructions for each lab before starting.
- Use the challenges only within their authorized CTF or training environments.
- Keep notes on discovered services, files, application information, and security observations.
- For reconnaissance labs, document what each discovery step reveals.
- For FTP exercises, record the relevant service behavior and security concepts.
- For SUID and wildcard labs, study why the demonstrated configuration creates a security risk.
- For keyring challenges, document the investigation process and learning objectives.
- Never apply these techniques against systems without explicit authorization.
